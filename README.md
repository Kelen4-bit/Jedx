# Grade 12 Developer Habit Tracker 🚀

A simple, effective habit tracking application designed for high school developers to build and maintain positive coding habits.

## Features

- ✅ **Track Daily Habits** - Monitor your coding practice, code reviews, documentation, and more
- 📊 **Progress Dashboard** - Visualize your habit streaks and consistency
- 🎯 **Goal Setting** - Set weekly and monthly goals
- 📈 **Analytics** - See your progress over time with charts and statistics
- 🏆 **Achievements** - Unlock badges as you reach milestones

## Habits to Track

- Daily coding practice (minutes/hours)
- Commit code to version control
- Write documentation
- Code reviews
- Testing practices
- Study time (algorithms, data structures, etc.)
- Side projects
- Community engagement
